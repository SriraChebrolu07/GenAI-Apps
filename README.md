# GenAI Apps

Experiments and prototypes built while learning generative AI application
development with Gemini, Groq, OpenAI, LangChain, RAG, Streamlit, SQL, AutoGen,
and CrewAI.

## Contents

- `apps/gemini` — Gemini chat, document, image, CSV, and multimodal examples
- `apps/groq` — Groq and document parsing experiments
- `apps/groq-streamlit` — Groq-powered Streamlit applications
- `apps/openai-langchain` — OpenAI, LangChain, PDF, email, and vector-store examples
- `apps/sql-ai` — Natural-language SQL and database AI prototypes
- `apps/misc` — Small standalone applications
- `agents/autogen-crewai` — Multi-agent and research workflows

These are learning prototypes rather than production-ready services. Configure
API keys and database credentials through a local `.env` file only.
